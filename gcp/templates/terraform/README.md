# Terraform Templates

Terraform-family lifecycle templates belong here.

Current templates:

- `cloud-storage/`: Cloud Storage bucket/object lifecycle target.
- `pubsub/`: Pub/Sub topic/subscription lifecycle target backed by the
  official Pub/Sub emulator.

Terraform and OpenTofu templates used for GCP provider compatibility tests
belong here.

Current templates:

- `cloud-storage/`: first Google provider lifecycle target for the bounded
  Cloud Storage runtime.
