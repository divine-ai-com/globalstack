# Pulumi Templates

Pulumi templates used for GCP provider compatibility tests belong here.

Current templates:

- `cloud-storage/`: Pulumi GCP provider lifecycle target for the bounded Cloud
  Storage runtime.
- `pubsub/`: Pulumi GCP provider lifecycle target for the official Pub/Sub
  emulator-backed runtime.
- `secret-manager/`: Pulumi GCP provider lifecycle target for the bounded
  Secret Manager runtime.
- `kms/`: Pulumi GCP provider lifecycle target for the bounded Cloud KMS
  runtime.
- `cloud-tasks/`: Pulumi GCP provider lifecycle target for the bounded Cloud
  Tasks queue and HTTP dispatch runtime.
- `logging/`: Pulumi GCP provider lifecycle target for the bounded Cloud
  Logging metric and structured log runtime.
